# ROS2_Engineering

面向机器人系统开发的 ROS 2 工程实践仓库，记录从环境搭建、基础通信到机器人模型、仿真调试的学习过程。

本仓库以古月居《ROS 2 入门21讲》为学习主线，注重 **工程实践、原理理解、问题排查与结果验证**，逐步将 ROS 2 知识应用于四足机器人等实际项目。

## 二、学习路线

### 01. 环境搭建与工程基础
- Ubuntu 开发环境配置

- 工作空间与功能包管理
- `colcon` 构建与依赖管理

### 02. ROS 2 核心通信
- Node：节点
- Topic：话题通信
- Service：服务通信
- Action：动作通信
- Parameter：参数管理
- 自定义 Message、Service 和 Action 接口

### 03. ROS 2 工程机制
- `package.xml` 与 `CMakeLists.txt`
- DDS 与 QoS
- 多节点 Launch 启动
- 分布式通信
- 节点运行状态与通信问题排查

### 04. 机器人模型与坐标变换
- TF2 坐标变换
- 静态与动态坐标系
- URDF 机器人模型描述
- Xacro 参数化与模块化建模
- `robot_state_publisher`
- 机器人模型与坐标系联动

### 05. 仿真与可视化
- Gazebo Sim 机器人仿真
- `ros_gz` 与 ROS 2 集成
- RViz 模型与传感器数据可视化
- RQt 图形化调试
- 仿真、话题与坐标变换综合验证

### 06. 项目集成与工程应用
- 多节点系统组织
- 传感器数据接入与处理
- 机器人运动控制接口
- 视觉感知与 ROS 2 通信集成
- 面向四足机器人项目的系统集成实践

## 三、仓库组织规范

- `README.md`：学习目标、核心原理、关键命令、代码说明、验证结果与总结。
- `workflow.md`：实际操作过程、执行命令、问题排查、解决方法与待办事项。

## 四、工程实践原则

1. **先理解原理，再验证行为**：不仅记录命令，还要理解节点、通信和系统组件之间的关系。
2. **以实际结果为准**：区分已完成、已验证、待验证与待解决的问题。
3. **保留排错过程**：记录错误信息、原因分析和解决方案，形成可复用的经验。
4. **确保可复现**：关键操作提供准确命令、必要配置和运行环境。
5. **持续工程化**：将分散的知识逐步整合为可运行、可调试的机器人系统。
