# ROS2 学习工作流 Day05｜古月居第10—12讲

## 一、本次学习内容

学习古月居 ROS2 入门21讲第10、11、12讲，整理 ROS 2 Humble 三大核心通信机制。

### 第10讲：自定义服务通信

- 学习 `.srv` 接口的请求与响应结构。
- 梳理自定义服务的功能包配置、接口生成和编译流程。
- 理解 C++ / Python 服务端与客户端的基本实现。
- 学习 `create_service()`、`create_client()`、`spin()` 和 `wait_for_service()`。

### 第11讲：参数通信

- 理解参数与节点的绑定关系。
- 学习参数声明、读取和修改。
- 整理 `ros2 param` 常用命令。
- 理解 YAML 参数保存与加载。
- 区分参数、Topic 和 Service 的适用场景。

### 第12讲：动作通信

- 理解 Action Client 与 Action Server 的职责。
- 学习 `.action` 文件的 Goal、Result 和 Feedback。
- 整理 Action 查询、接口查看和目标发送命令。
- 理解执行反馈、最终结果及取消请求流程。

## 二、阶段性成果

- 完成第10—12讲知识点整理。
- 建立 Topic、Service、Action 三大通信机制的对比认知。
- 整理常用 ROS 2 命令和核心 API。
- 明确不同通信机制在机器人系统中的应用场景。
